# StudyCircle

StudyCircle is a web application that helps university students create, discover, join, and manage study groups for their courses.

## Team Members

- Yerlin Rodriguez — Team Lead and Developer

I was the only participating member available for the project activities. I completed the project planning, development setup, architecture planning, data modeling, design planning, documentation, and GitHub project management.

## Tech Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- ESLint
- Prettier
- PostgreSQL
- Prisma ORM

## Git Workflow

- `main` is the primary branch.
- Development work is completed on feature branches.
- Changes are submitted through pull requests.
- Changes are reviewed before being merged into `main`.
