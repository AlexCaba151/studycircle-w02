# StudyCircle

StudyCircle is a web application that helps university students create, discover, and manage study groups for their courses.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint
- Prettier

## Git Workflow
- `main` is protected.
- All work uses feature branches such as `feature/study-groups`.
- Pull requests are required before merging into `main`.
- At least one teammate reviews every pull request.
