## Selected Proposal

**StudyCircle — University Study Group Organizer**

StudyCircle is a web application that helps university students create, discover, join, and manage study groups for their courses.

## Why We Selected It

The team selected StudyCircle because the idea has a clear MVP, can be implemented with the required Next.js/TypeScript/Tailwind stack, and provides several meaningful CRUD and collaboration workflows. The project also gives the team opportunities to demonstrate authentication, responsive UI, API development, data modeling, and GitHub collaboration.

## Decisions

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- Prettier
- Protected `main`
- Feature branches
- Pull requests with at least one reviewer
- GitHub Project Board for issue tracking
- Spec-Kit specification stored in `docs/specification.md`
